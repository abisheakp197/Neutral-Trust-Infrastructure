NTI Witness Evidence Package

Fixed verification location for external witnesses

This directory is the stable location where external witnesses (such as HORIZON SHIELD) recompute and verify the cryptographic state of Neutral Trust Infrastructure. Every artifact is an input to be re-derived, not a claim to be accepted.

Artifacts

  • MANIFEST.json — SHA-256 of NTI's native test scripts and build manifests, pinned to an exact commit.
  • RESULTS.json — recorded outcomes of NTI's native Rust and Python suites.
  • PUBLIC_KEY.pem — Ed25519 public key.
  • SIGNATURE.sig — 64-byte Ed25519 signature over RESULTS.json || MANIFEST.json.
  • verify.sh — self-contained verifier.
  • README.md — full documentation.

How to verify

cd conformance/witness && ./verify.sh /path/to/Neutral-Trust-Infrastructure

By hand:

cat RESULTS.json MANIFEST.json > /tmp/to_sign.bin
openssl pkeyutl -verify -pubin -inkey PUBLIC_KEY.pem -rawin -in /tmp/to_sign.bin -sigfile SIGNATURE.sig

Scope and limits.

  • This package covers NTI's own test suites only. No third-party or external conformance suite is included or referenced.
  • The public key has no external trust anchor. A valid signature proves the two JSON files are intact, not who produced them.
